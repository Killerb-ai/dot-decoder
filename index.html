📌 특허 기술 원리

문건 식별코드(예: 25163047)는 아래 구조로 문건에 삽입됩니다:

1. 전체영역을 2행×4열 = 8개의 기본분할영역으로 나눕니다
2. 각 기본분할영역을 4열×2행 = 8개의 세부분할영역으로 세분화합니다
3. 코드의 k번째 자릿수 D[k] → 기본분할영역 k 안의 세부분할영역 D[k]번에 점을 찍습니다
4. 총 8개의 점이 각 기본분할영역에 하나씩 삽입됩니다
🔓 디코더 사용법

1. 디코더 탭에서 스캔 이미지를 업로드합니다
2. 영역 자동 감지가 적용됩니다 (필요시 수동 조정)
3. 임계값/점 크기 파라미터를 조정합니다
4. 분석 시작 버튼을 클릭합니다
5. 하단에 8자리 문건 식별코드가 표시됩니다
🔒 인코더 사용법 (테스트)

1. 인코더 탭에서 8자리 숫자를 입력합니다 (각 자릿수 0~7)
2. 이미지 생성을 클릭하면 해당 위치에 점이 삽입된 이미지가 만들어집니다
3. PNG 다운로드로 저장 후 인쇄 → 스캔 → 디코더로 검증 가능
⚠️ 스캔 이미지 주의사항

• 300 DPI 이상의 고해상도 스캔 권장
• 이미지가 기울어진 경우 자동 감지 정확도 저하
• 임계값을 조정하여 감도를 최적화하세요
• 텍스트가 매우 조밀한 경우 점 크기 필터(최소/최대)를 좁혀보세요
