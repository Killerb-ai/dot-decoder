📖 사용 가이드

KR 10-1989170 특허 기반 점은닉 디코더 v4.0 사용법

🆕 v4.0 배경이상도 알고리즘 (Local Background Anomaly)

각 분할영역의 로컬 배경 대비 어두운 픽셀을 탐지:

1. 그레이스케일 변환 후 기본분할 영역별 배경(88백분위) 추정
2. BFS 연결성분 분석으로 인접 픽셀 그룹을 찾습니다
3. 이상도 = max(0, 로컬배경 - 픽셀) 계산 — 배경보다 어두울수록 높은 이상도
4. 텍스트(100 미만 어두운 픽셀)는 노이즈 제거를 위해 이상도 계산에서 제외
5. 8개 기본분할 각각에서 이상도 합계가 최고인 세부분할 위치 = 해당 자릿수
📌 특허 기술 원리

문건 식별코드(예: 25163047)는 아래 구조로 문건에 삽입됩니다:

1. 전체영역을 4행×2열 = 8개의 기본분할영역으로 나눕니다
2. 각 기본분할영역을 2행×4열 = 8개의 세부분할영역으로 세분화합니다
3. 코드의 k번째 자릿수 D[k] → 기본분할영역 k 안의 세부분할영역 D[k]번에 점을 찍습니다
4. 총 8개의 점이 각 기본분할영역에 하나씩 삽입됩니다
🔓 디코더 사용법

1. 디코더 탭에서 스캔 이미지를 업로드합니다
2. 분석 시작 버튼을 클릭합니다
3. 하단 세부분할영역 확대 그리드에서 각 P0~P7의 실제 점 위치를 확인합니다
4. 잘못 감지된 경우 해당 셀을 클릭하여 수동으로 지정합니다
5. 또는 이미지를 직접 클릭하는 수동 마킹 모드를 사용합니다
⚙️ 파라미터 조정 팁

• 어두운 임계값 (기본 130): 올리면 텍스트 픽셀 더 제거 (점이 진하면 낮추기)
• 밝은 임계값 (기본 220): 낮추면 순수 흰 배경 픽셀 제거
• 최소 원형도 (기본 0.20): 낮추면 더 많은 후보 허용, 높이면 더 엄격히 걸러냄
• 300 DPI 이상의 고해상도 스캔 권장
• 감지가 실패할 경우 어두운 임계값을 낮추거나(110), 원형도를 낮춰보세요(0.15)
